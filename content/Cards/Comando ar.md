- comando arquivador de arquivos de biblioteca estática (do tipo .a)
	- `r` => replace, se o arquivo já existe substitua
	- `c` => create, se não existe crie
	- `s` => indica que os headers devem ser atualizados para o linker (ligador) funcionar.
