## Kitty

### Gerenciamento De Janelas E Abas

- Ctrl+Shift+Enter: Nova janela
- Ctrl+Shift+W: Fechar janela atual
- Ctrl+Shift+]: Focar na janela vizinha
- Ctrl+Shift+F: Mover janela ativa para frente
- Ctrl+Shift+B: Mover janela em uma direção específica
- Ctrl+Shift+`: Mover janela ativa para o topo
- Ctrl+Shift+L: Alternar entre layouts

### Rolagem E Visualização

- Ctrl+Shift+H: Mostrar histórico de rolagem no paginador
- Ctrl+Shift+Up: Rolar uma linha para cima
- Ctrl+Shift+Down: Rolar uma linha para baixo
- Ctrl+Shift+Page_Up: Rolar uma página para cima
- Ctrl+Shift+Page_Down: Rolar uma página para baixo
- Ctrl+Shift+Home: Rolar para o topo do buffer
- Ctrl+Shift+End: Rolar para o fim do buffer

### Área De Transferência

- Ctrl+Shift+C: Copiar texto selecionado para a área de transferência
- Ctrl+Shift+V: Colar da área de transferência
- Ctrl+Shift+S: Colar da seleção
- Ctrl+Shift+O: Passar texto selecionado para um programa

### Tamanho Da Fonte E Configuração

- Ctrl+Shift+Equal: Aumentar tamanho da fonte
- Ctrl+Shift+Minus: Diminuir tamanho da fonte
- Ctrl+Shift+Backspace: Restaurar tamanho original da fonte
- Ctrl+Shift+F5: Recarregar arquivo de configuração

### Outros Atalhos Úteis

- Ctrl+Shift+E: Clicar em URLs usando o teclado
- Ctrl+Shift+Escape: Executar o shell do kitty para controlar com comandos
- Ctrl+Shift+Delete: Limpar o terminal

### Navegação Entre Janelas (Configurável)

É possível configurar atalhos adicionais no arquivo kitty.conf para facilitar a navegação, como:

- Ctrl+Esquerda: janela vizinha à esquerda
- Shift+Esquerda: mover janela para a direita
- Ctrl+Baixo: janela vizinha abaixo
- Shift+Baixo: mover janela para cima

Para personalizar estes atalhos ou criar novos, você pode editar o arquivo de configuração do Kitty pressionando Ctrl+Shift+F2 ou editando diretamente o arquivo em ~/.config/kitty/kitty.conf.
